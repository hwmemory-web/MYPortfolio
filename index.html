Cloud Migration & Identity

OO그룹 M365 도입 및 하이브리드 AD 구축

Role Lead System Engineer
Period 2023.03 - 2023.09 (6개월)
Client OO 제조 그룹사

Project Overview

전국 5개 지사를 보유한 고객사의 노후화된 온프레미스 인프라를 Microsoft 365 기반의 클라우드 환경으로 전환하고, 보안 강화를 위해 하이브리드 ID 체계를 구축한 프로젝트입니다.

Azure AD Connect Exchange Online Windows Server 2022 PowerShell

Architecture

온프레미스 AD와 Azure AD 간의 일관된 사용자 경험을 제공하기 위해 Password Hash Synchronization 방식을 채택하였습니다.

[이곳에 아키텍처 구성도 이미지를 삽입하세요]

Key Responsibilities

  • 설계: 멀티 도메인 환경에서의 Azure AD Connect 동기화 범위 및 필터링 정책 설계
  • 구축: Windows Server 2022 기반의 신규 DC 구축 및 FSMO 역할 전송
  • 이관: 기존 Exchange 2016 서버에서 Exchange Online으로 하이브리드 마이그레이션 수행 (1,200명 유저)

Challenges & Solutions

Problem: 동기화 과정에서 기존 온프레미스 계정의 중복 및 UPN 불일치로 인한 동기화 오류 대거 발생.

Solution: PowerShell 스크립트를 작성하여 전사 계정의 ID 전수 조사를 실시하고, 중복된 메일 주소 및 특수문자가 포함된 UPN을 일괄 정제하는 전처리 과정을 통해 동기화 성공률 100% 달성.
